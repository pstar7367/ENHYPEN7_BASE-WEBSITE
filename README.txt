# ENHYPEN7_BASE website

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code's Live Server extension.
3. The supplied cross/wings image is in `assets/cross-wings.jfif`.

## Before publishing
- Replace the Google Forms placeholder (`https://forms.google.com/`) in `index.html` with your actual membership form URL.
- Replace social `href="#"` values with the fanbase's real social profile URLs.
- The July 2026 schedule entries are illustrative entries transcribed from the supplied design; verify dates and details before publishing.
- Google Fonts are loaded online; system fallbacks are included.
